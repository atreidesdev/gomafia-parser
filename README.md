# Gomafia Parser + Stats Dashboard

Инструмент для сбора и анализа игровой статистики с gomafia.pro. Состоит из двух частей: парсер (собирает данные в JSON) и дашборд (визуализирует их в браузере).

## Требования

Node.js LTS 18+ и npm (ставятся вместе). Проверка: node -v и npm -v. Плюс интернет для парсера и любой современный браузер для дашборда.

## Установка

cd /путь/к/папке/проекта

npm install

npx playwright install chromium

## Запуск парсера

npm run start

Парсер задаст три вопроса:

1. Ссылка на профиль - вида https://gomafia.pro/stats/1373.
2. Режим сбора (1–11): все победы, все поражения, мирный, шериф, маф, дон, мирные-победы, мирные-поражения, чёрные-победы, чёрные-поражения, все игры. Если сомневаетесь - выбирайте 11.
3. Диапазон турниров: от 1 (самый новый) до нужного номера.

Результат сохраняется в папку results как PlayerName-режим_1-50.json.

## Просмотр статистики

Откройте stats.html в браузере, нажмите «Загрузить JSON» и выберите файл из results. Если браузер блокирует локальные файлы - запустите npx serve . и откройте адрес из терминала.

## Что показывает дашборд

Вкладка «Визуализация» - журнал игр. Сводка по турнирам и играм, инсайты (смерть шерифа в 1 ночь, уход в 1 ночь), серии побед и поражений по ролям, винрейт по ролям и по позициям за столом. Фильтры по результату, роли, качеству игры, первому ушедшему, смерти шерифа, MVP, типу турнира, финалу. Поиск по одному или нескольким игрокам через запятую. Сортировка игр. Режим «скрыть чужие роли». Карточки игр с составом стола, очками, иконками, копированием строки «Турнир, СТОЛ N, ДД.ММ» и переходом к нужному туру.

Вкладка «Аналитика» - взгляд сверху. Сводка: игры, винрейт, средний балл. Карточки по ролям. Круговая диаграмма распределения ролей. Радар стиля игры (6 метрик по всем ролям или отдельно по выбранной). График винрейта (по турнирам или скользящее окно 10/20/50 с зумом). График ELO (накопительный или дельта по турнирам). Тепловая карта партнёров с разными режимами и сортировкой. Детальная таблица партнёров с фильтрами, сортировкой и экспортом в CSV.

Вкладка «Шерифы» - дуэли с каждым шерифом. Три блока: красная команда (я мирный + шериф, я шериф + мирный, итого), я шериф против чёрных (vs мафия, vs дон, итого), я чёрный против шерифа (я дон, я мафия, итого). Для каждой пары игры и винрейт. Клик по числу игр открывает список партий. Поиск, фильтр по датам и минимальному числу игр.

Вкладка «Судьи» - статистика по каждому судье: общее число игр, разбивка по ролям (игры, винрейт, средний балл), итоговая строка. Поиск, сортировка, фильтры по датам и минимальному числу игр. Клик по числу игр открывает партии.

Общее: тёмная и светлая темы, автономная работа (данные никуда не уходят), экспорт в CSV, копирование названий турниров и игровых строк.

## Если что-то не работает

Парсер нашёл ноль игр - проверьте ссылку на профиль и диапазон турниров. Если сайт обновился, парсер может перестать видеть игры - сообщите.

Ошибка про браузер при первом запуске - выполните npx playwright install chromium.

Дашборд не открывается с диска - запустите npx serve . в папке проекта.

Дашборд пустой - убедитесь, что загружаете файл из results и не включён фильтр, отсекающий все игры.
