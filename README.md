# Gomafia Parser + Stats Dashboard

🌐 **Онлайн-версия:** [https://atreidesdev.github.io/gomafia-parser/](https://atreidesdev.github.io/gomafia-parser/)

Инструмент для сбора и анализа игровой статистики с gomafia.pro.

---

## 🛠️ Инструменты в проекте

### 1. 🏆 `index.html` (Главный хаб)

Красивая стартовая страница-навигатор по центру экрана. Служит точкой входа для переключения между просмотром турниров и аналитикой.

### 2. 🎮 `tournament-viewer.html` (Просмотр турниров)

Интерактивный дашборд-журнал партий:

* Загрузка базы турниров из JSON-файла.
* Продвинутая панель фильтров с поддержкой поиска по игрокам, режимов («любой» / «все»), выбора конкретных турниров, типов побед, раундов и минимального ELO стола.
* **Скрытие чужих ролей** (через плавный переключатель-свич) для тренировки памяти и чтения игры.
* Отметки о просмотренных играх (`✅ Просмотрено`) и **Избранном** (`⭐ В избранное`).
* Экспорт и импорт отметок (`localStorage`) в JSON-файл для сохранения прогресса между сессиями.

### 3. 📊 `stats.html` (Статистика и аналитика)

Глубокая аналитическая панель:

* Сводные показатели, винрейт по ролям и позициям за столом (1–10).
* Графики изменения ELO (накопительный / дельта) и GG по годам с разметкой Топ-12.
* Радар стиля игры, графики винрейта со скользящим окном и зумом, анализ серий (тильт / разгон) и усталости по номеру игры в турнире.
* Тепловая карта синергии с партнёрами и детальная таблица с экспортом в CSV.
* Вкладки с аналитикой дуэлей против шерифов и судейским составом.

### 4. 🤖 `scraper.js` (Парсер турниров по игроку)

Интерактивный скрипт для сбора статистики профиля с `gomafia.pro` (с поддержкой пакетной обработки из файла `players.txt`).

### 5. 📦 `tournament-parser.js` (Парсер конкретных турниров)

Парсер по ID или ссылкам турниров с возможностью обогащения данных ELO через кэш.

### 6. 🧠 Кэш ELO и утилиты

* **`eloCache.js`** и **`buildEloCache.js`** — модули для создания и наполнения локального кэша ELO игроков (`elo-cache.json`).
* **`enrichTournaments.js`** — скрипт автоматического добавления ELO игроков и расчета среднего ELO столов в JSON-результаты.

## 📋 Требования и установка

Node.js LTS 18+ и npm.

```bash
# Установка зависимостей
npm install

# Установка браузера для Playwright
npx playwright install chromium

```

---

## 🚀 Как запускать скрипты

### 1. Интерактивный парсер профиля игрока (`scraper.js`)

```bash
npm start
# или: node scraper.js

```

*Скрипт запросит ссылку на профиль, режим сбора (1–14) и диапазон турниров. Результаты сохраняются в папку `results/`.*

### 2. Парсер конкретных турниров (`tournament-parser.js`)

```bash
# Сбор по ID или прямым ссылкам
node tournament-parser.js 2659 2760 https://gomafia.pro/tournament/3299

# Чтение списка турниров из текстового файла
node tournament-parser.js --file tournaments.txt

# Перезаписать уже существующие турниры в базе
node tournament-parser.js --force

```

### 3. Сбор и обновление локального кэша ELO игроков (`buildEloCache.js`)

```bash
# Наполнение кэша из результатов в папке results
node buildEloCache.js --from-results ./results

# Сбор по конкретным ID игроков
node buildEloCache.js --ids 1-10000

```

### 4. Обогащение результатов ELO (`enrichTournaments.js`)

Добавляет значения ELO к игрокам и рассчитывает среднее ELO столов в ранее сохраненных JSON-файлах:

```bash
node enrichTournaments.js

```

### 5. Локальный просмотр дашбордов в браузере

Если браузер блокирует открытие HTML-файлов напрямую с диска (`file://`), запустите локальный сервер:

```bash
npx serve .

```

*Затем откройте в браузере появившийся адрес (например, `http://localhost:3000`).*
